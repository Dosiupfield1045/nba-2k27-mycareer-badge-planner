## 它能做什么

- **徽章要求清单.** 将已完成的会话转换为可读的进度或比赛历史记录。

- **MyCAREER 会话跟踪.** 将总计分为几类，以解释取得或失去进展的情况。

- **进度和同步诊断.** 记录同步时间和跳过的会话，以便诊断丢失的数据。

## 如何理解结果

趋势需要多个已完成的会话和值得信赖的同步时间。除了要求或产生这些成果的比赛详细信息之外，请阅读最近的成果。如果缺少一项，请避免手动编辑总计，直到原始来源确认会话是否不完整、延迟或重复。

## 开始之前

- 准备好 **会话或比赛历史记录**，并确认它属于目标 NBA 2K27 配置或会话。
- 更改配置之前，记录当前游戏/客户端版本或数据日期。
- 提前选择 **本地历史导出** 的保存位置，避免覆盖上一次结果。
- 先用 **徽章要求清单** 进行一次短测试，并保留原始存档、配置或对比记录。

## 完成第一次使用

1. 打开 **NBA 2K27 MyCAREER 徽章升级规划器**，确认检测到的 NBA 2K27 版本或数据源。
2. 选择输入或配置，只设置 **徽章要求清单**，暂时保留与本次测试无关的默认值。
3. 在预览或状态面板检查 **MyCAREER 会话跟踪**，处理版本、筛选或识别警告。
4. 只执行一次可控操作。在修改第二项设置之前，将实际结果与预览进行对比。
5. 保存配置或导出结果，并保留 **进度和同步诊断** 以便对比或恢复。

## 故障排查

> **常见故障:** 游戏结束后徽章进度不更新.

### 最近的会话丢失

将上次同步时间与已完成的匹配进行比较，并仅刷新所选数据源。

### 进度不变

打开要求清单并确认会话满足跟踪条件。

### 叠加层显示旧总计

历史视图完成同步后重新加载布局。
