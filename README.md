## What it does

- **badge requirement checklist.** Turns completed sessions into a readable progress or match history.

- **MyCAREER session tracking.** Breaks totals into the categories that explain where progress was gained or lost.

- **progress and sync diagnostics.** Records sync time and skipped sessions so missing data can be diagnosed.

## How to read the result

A trend needs several completed sessions and a trustworthy sync time. Read recent gains beside the requirements or match details that produced them. If one entry is missing, avoid editing totals manually until the raw source confirms whether the session was incomplete, delayed or duplicated.

## Before you begin

- Keep **Session or match history** ready and confirm that it belongs to the intended NBA 2K27 profile or session.
- Note the current game/client build or data date before changing a profile.
- Choose where **Local history export** will be saved so the previous result is not overwritten.
- Use **badge requirement checklist** in one short test first; keep the original save, profile or comparison beside it.

## A complete first run

1. Open **NBA 2K27 MyCAREER Badge Progression Planner** and confirm the detected NBA 2K27 build or data source.
2. Select the input or profile, then configure **badge requirement checklist** without changing the defaults that are not part of this test.
3. Review **MyCAREER session tracking** in the preview or status panel and correct any version, filter or detection warning.
4. Run one controlled action. Compare the visible result with the preview before changing a second setting.
5. Save the profile or export the result, keeping **progress and sync diagnostics** available for recovery and comparison.

## Troubleshooting

> **Common failure pattern:** badge progress does not update after a game.

### A recent session is missing

Compare the last sync time with the completed match and refresh only the selected data source.

### Progress is unchanged

Open the requirement checklist and confirm that the session met the tracked condition.

### The overlay shows old totals

Reload the layout after the history view finishes synchronization.
