## 🛠️ Troubleshooting Common Issues

### The app won't start after installation

- Restart your computer and try again
- Make sure you're running the latest Windows updates
- Temporarily disable antivirus software if it's blocking the app (then re-enable it)

### Windows shows a "Unknown Publisher" warning

This is normal for independently developed apps. Click **More info**, then **Run anyway**. The app is safe to use.

### My progress isn't saving

- Make sure the app is installed in a location where you have write permissions (like `C:\Users\YourName\AppData\Local`)
- Check that your user account has standard read/write permissions

### The app looks blurry or small on screen

- Right-click the app icon and select **Properties**
- Go to the **Compatibility** tab
- Click **Change high DPI settings**
- Check "Override high DPI scaling behavior" and select "Application"
