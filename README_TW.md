## 主要功能

- **徽章要求清單.** 將已完成的會話轉換為可讀的進度或比賽歷史記錄。

- **MyCAREER 會話跟踪.** 將總計分為幾類，以解釋取得或失去進展的情況。

- **進度和同步診斷.** 記錄同步時間和跳過的會話，以便診斷遺失的資料。

## 如何理解結果

趨勢需要多個已完成的會話和值得信賴的同步時間。除了要求或產生這些成果的比賽詳細資訊之外，請閱讀最近的成果。如果缺少一項，請避免手動編輯總計，直到原始來源確認會話是否不完整、延遲或重複。

## 開始之前

- 先用 **徽章要求清單** 進行一次短測試，並保留原始存檔、設定或比較記錄。

## 完成第一次使用

1. 開啟 **NBA 2K27 MyCAREER 徽章升級規劃器**，確認偵測到的 NBA 2K27 版本或資料來源。
2. 選擇輸入或設定，只調整 **徽章要求清單**，先保留與本次測試無關的預設值。
3. 在預覽或狀態面板檢查 **MyCAREER 會話跟踪**，處理版本、篩選或辨識警告。
4. 只執行一次可控制的操作。在修改第二項設定之前，將實際結果與預覽比較。
5. 儲存設定或匯出結果，並保留 **進度和同步診斷** 以便比對或還原。
